## 💡 핵심 요약

1. **한국투자증권**이 유일하게 해외주식 REST API를 완전 지원
2. **키움증권** REST API 출시했으나 **해외주식 미지원** (국내 주식만 지원)
3. 수수료는 한국투자증권이 타사 대비 **5.7~8.3배 높음**
4. **API 제공과 낮은 수수료를 동시에 만족하는 증권사 없음**

## 3. 주요 증권사 API 상세 분석

### 🏆 한국투자증권 (유일한 해외주식 API 제공)

#### 장점
- 국내 증권사 **최초 Open API 제공** (2022.04)
- **REST API 방식**으로 다양한 OS 지원 (Windows, macOS, Linux)
- ChatGPT, Claude 등 **AI 환경과 연동 가능**
- GitHub에 **샘플 코드 및 SDK 제공**
- **웹소켓 실시간 데이터 지원**
- 미국 주식 포함 해외 주식 거래 완벽 지원

#### 단점
- **업계 최고 수준의 수수료 (0.25%)**
- 타사 대비 5.7~8.3배 높은 수수료
- 빈번한 거래 시 수수료 부담 큼

#### 참고 자료
- 개발자센터: https://apiportal.koreainvestment.com/intro
- GitHub: https://github.com/koreainvestment/open-trading-api
- WikiDocs 가이드: https://wikidocs.net/165185

---

### ⚡ 키움증권 (REST API 출시, 해외주식 미지원)

#### 현황
- **2024년 3월 REST API 서비스 출시**
- **국내 주식 거래 완벽 지원**
- KRX 금현물 거래 API 추가
- **중요: 해외주식 API 지원 여부 불명확**
- 향후 해외주식 지원 가능성 존재

#### 기존 Open API+ (COM 방식)
- ActiveX/OCX 기반 (Windows 전용)
- 국내 주식 전용
- 해외주식 미지원

#### 수수료
- 0.044% (삼성증권 대비 1.5배 높지만 한투 대비 5.7배 저렴)

#### 참고 자료
- REST API: https://openapi.kiwoom.com/
- Open API+ 다운로드: https://www.kiwoom.com/h/common/bbs/VBbsBoardBWOAZView
- REST API 출시 뉴스: https://www.hankyung.com/article/202503243715P

## 4. 프로젝트 적용 시 결정 사항

### 현재 상황
- **키움증권 Open API+는 해외주식(미국주식) 미지원**
- **키움증권 REST API도 해외주식 미지원 (2024년 3월 기준)**

### 선택지

#### 옵션 1: 한국투자증권 API로 전환 ⭐ 권장
- **장점**:
  - 해외주식 완벽 지원
  - REST API 방식으로 개발 편의성 높음
  - 공식 문서 및 샘플 코드 풍부
  - C# 환경에서도 사용 가능
  
- **단점**:
  - 높은 수수료 (0.25%)
  - 기존 키움 API 코드 전면 재작성 필요

- **적용 방법**:
  1. 한국투자증권 계좌 개설
  2. Open API 신청 (https://apiportal.koreainvestment.com/)
  3. REST API 기반으로 프로젝트 재설계
  4. C# HttpClient를 사용한 REST API 호출 구현

#### 옵션 2: 키움증권 + 외부 데이터 소스 조합
- **장점**:
  - 기존 키움 API 코드 활용 가능
  - 낮은 수수료 유지 (0.044%)
  
- **단점**:
  - 복잡한 아키텍처
  - 외부 API 의존성 증가
  - 실시간 데이터 동기화 어려움

- **적용 방법**:
  1. **외부 API로 거래대금 상위 300종목 확보**:
     - Yahoo Finance API
     - Alpha Vantage
     - Finnhub
     - Polygon.io
  2. **키움 API로 실시간 시세 감시**:
     - 확보된 종목 리스트를 실시간 등록
     - 조건식 평가 및 매수 실행
  3. **데이터 동기화 로직 구현**:
     - 1분 주기로 외부 API에서 종목 리스트 갱신
     - 키움 API 실시간 등록 업데이트

#### 옵션 3: 프로젝트 범위 변경 (국내 주식으로 전환)
- **장점**:
  - 키움 API 그대로 사용 가능
  - 낮은 수수료
  - 기술적 복잡도 최소화
  
- **단점**:
  - 원래 목표(미국 주식)와 다름
  - 시장 특성 차이 (거래 시간, 변동성 등)

## 5. 권장 사항

### 단기 (프로토타입 개발)
1. **한국투자증권 API로 전환**하여 프로토타입 개발
2. REST API 방식이므로 개발 속도가 빠름
3. 수수료는 실거래 전까지는 큰 문제 아님

### 중기 (실거래 준비)
1. 수수료 부담이 크다면 **옵션 2 (키움 + 외부 API)** 검토
2. 거래 빈도와 수수료를 계산하여 손익분기점 분석

### 장기 (확장성)
1. 키움증권의 REST API 해외주식 지원 여부 지속 모니터링
2. 다른 증권사의 API 출시 동향 주시
3. 복수 증권사 API 지원 아키텍처 고려
