# PRD (Product Requirements Document) v3.0

**프로젝트명**: **한국투자증권 API** 기반 미국주식 거래대금 상위 300종목 자동 스크리닝 및 종가 자동매매 시스템

**버전**: 3.0
**작성일**: 2025년 11월 10일
**기준 API**: 한국투자증권(KIS) REST & WebSocket API

---

## 1) 시스템 개요

### 목적

- **한국투자증권(KIS) API**를 사용하여 미국 주식시장(뉴욕, 나스닥)의 **거래대금 상위 300개 종목**을 자동으로 선별한다.
- 사용자가 설정한 조건식(등락률, 이동평균, 거래대금, 주가비교 등)을 실시간으로 평가한다.
- 장마감 10분 전, 조건이 충족된 종목 중 **하락률이 가장 높은 2개**를 선정하여 **LOC(Limit on Close) 주문**으로 자동 분할 매수한다.
- ETF, ETN, 레버리지 종목을 모두 포함하여 투자 기회를 극대화한다.

### 핵심 기능

| 기능 | 상세 내용 |
|---|---|
| **대상 종목 자동 스크리닝** | KIS API를 통해 미국 시장(NYS, NAS) 거래대금 상위 300종목 리스트를 주기적으로 자동 갱신 | 
| **실시간 조건 감시** | 300개 종목의 실시간 시세를 WebSocket으로 수신하여 사용자 정의 조건식 충족 여부 평가 | 
| **자동 종가 매수** | 장마감 10분 전, 조건 충족 후보 중 하락률 상위 2개 종목을 LOC(+5%) 주문으로 자동 분할 매수 | 
| **자금 관리** | 후보가 1개일 경우 100% 매수, 2개일 경우 각 50%씩 분할 매수 | 
| **안정적 운영** | VPS 서버 환경에서 24시간 무중단 운영을 목표로 설계 |

## 2) 운용 시나리오

1.  **프로그램 실행 및 인증**: 사용자가 VPS 환경에서 프로그램을 실행하면, 시스템은 자동으로 한국투자증권 API 서버에 인증하여 **Access Token**과 **WebSocket 접속키(approval_key)**를 발급받는다.

2.  **거래대금 상위 종목 확보**: **15분 주기**로 KIS REST API(**HHDFS76320010**)를 호출하여 뉴욕(150개), 나스닥(150개)의 거래대금 상위 종목 리스트를 확보하고 최신 상태로 갱신한다.

3.  **실시간 시세 구독**: 확보된 300개 종목에 대해 **8개의 WebSocket 세션**을 생성하여 실시간 체결가(**HDFSCNT0**)를 구독한다. (세션당 41종목 제한 준수)

4.  **조건식 설정**: 사용자는 UI를 통해 최대 3개의 조건식을 AND/OR 조합으로 설정한다.

5.  **장중 조건 평가**: 시스템은 수신되는 실시간 시세 데이터를 기반으로 300개 전 종목의 조건 충족 여부를 장중 내내 평가하며, 조건 충족 시 후보 리스트를 내부적으로 유지한다.

6.  **최종 매수 결정 및 주문**: 
    - **장마감 10분 전**부터 조건 충족 결과를 확정하기 시작한다.
    - 노이즈 필터링을 위해 **2회 연속(예: 10초 간격) 조건이 True**로 유지되는 종목만 최종 후보로 확정한다.
    - 최종 후보 리스트에서 **하락률이 가장 높은 순으로 2종목**을 선정한다.
    - 선정된 종목에 대해 **현재가의 +5% 가격**으로 **LOC 지정가 매수 주문**을 자동 실행한다. (1종목 시 100%, 2종목 시 각 50% 자금 배분)

7.  **결과 로깅**: 모든 거래 시도(주문 포함) 및 시스템 상태는 로그 파일에 자동으로 기록된다.

## 3) 지원 조건식 항목 (최대 3개 조합)

*조건식 계산에 필요한 데이터(일봉, 주봉 등)는 KIS REST API를 통해 사전에 조회하여 메모리에 적재 후, WebSocket으로 수신되는 실시간 현재가와 결합하여 평가한다.*

| 조건식 | 상세 내용 |
|---|---|
| **A) 등락률 조건** | - **기준봉**: 일봉 / 주봉<br>- **기준**: n봉 전 시가/종가/고가/저가 대비 변동률<br>- **입력**: 하한% ~ 상한% | 
| **B) 이동평균선 조건** | - **기준봉**: 일봉<br>- **이평선**: 10 / 20 / 120 이평<br>- **조건**: 현재가가 n일 이평선 대비 ±m% 이내 또는 이상/이하 | 
| **C) 거래대금 조건** | - **기준**: 당일 누적 거래대금<br>- **입력**: 최소 거래대금 (예: 1,000만 달러 이상) | 
| **D) 주가 비교 조건** | - **기준봉**: 일봉<br>- **요소**: 시가, 종가, 고가, 저가<br>- **조건**: (a봉 Y요소) > (b봉 Z요소) 형태의 비교 | 

### 조건 조합 방식
- 조건식들은 **AND / OR** 조합 가능
  - 예: `(A AND B) OR C`, `A AND B AND C`, `A OR B OR C`

## 4) 매수 방식

| 항목 | 내용 |
|---|---|
| **매수 시점** | 미국 정규장 마감 10분 전 조건 충족 확정 시 |
| **주문 방식** | **LOC (Limit on Close)** - 종가 지정가 |
| **주문 가격** | **현재가 × 1.05 (5% 높게)**<br>*(종가가 주문 가격 이하일 때만 체결)* |
| **매수 수량** | **총 자산 × 사용자 입력 비율 %**<br>*(후보 1개: 100%, 2개: 각 50%)* |
| **매도 기능** | 없음 |
| **보유 종목 재진입 방지** | 옵션 선택 시, 기보유 종목은 매수 후보에서 제외 |
| **서머타임** | KIS API에서 제공하는 거래소 정보를 통해 **자동 반영** |

## 5) UI 요구사항 (v2.0 기반)

| UI 영역 | 설명 |
|---|---|
| **메인 대시보드** | - **API 접속 상태**: 실전/모의, 접속/단절<br>- **계좌 정보**: 총 자산, 예수금, 총 매입, 총 평가<br>- **미국 시장 상태**: 개장/폐장, 서머타임 여부, 거래소 마감시간 |
| **매매 설정** | - **매수 비율(%) 입력**<br>- **보유 종목 재진입 방지 옵션** (체크박스) |
| **조건식 슬롯** | - 최대 3개의 조건식을 드롭다운으로 선택<br>- 각 조건식의 세부 파라미터(봉, 요소, 부등호, 값 등) 입력 UI |
| **감시 현황** | - **거래대금 상위 300 리스트**: 실시간으로 스크롤 가능한 그리드<br>- **조건 충족 후보**: 조건식 결과가 True인 종목을 리스트에 별도 표기(예: 하이라이트) |
| **실시간 상태** | - **장마감 카운트다운**: T-10분부터 카운트다운 표시<br>- **주문 예정 목록**: 최종 선정된 매수 후보 2종목 표시 |
| **로그 출력** | - 시스템의 모든 주요 이벤트(API 호출, 조건 충족, 주문 실행 등)를 실시간으로 출력<br>- 로그는 파일로 자동 저장 |

## 8) 시스템 전제 조건 (VPS 환경)

| 항목 | 내용 |
|---|---|
| **API** | **한국투자증권(KIS) REST & WebSocket API** |
| **실행 환경** | Windows Server 2019+ / CPU 4vCore / RAM 8GB 권장 |
| **API 호출 제한** | **초당 20회(실전), 5회(모의)** 제한을 준수하도록 Throttling Queue 구현 |
| **실시간 시세** | **WebSocket 8개 세션**을 사용하여 300종목 동시 구독 |
| **안정성** | - API 호출 실패 시 **지수 백오프(Exponential Backoff)** 기반 재시도 로직 구현<br>- WebSocket 연결 단절 시 자동 재연결 로직 구현 |
