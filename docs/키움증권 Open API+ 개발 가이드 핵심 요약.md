## 핵심 개념

### 1. 설치 및 개발환경

#### 모듈설치
- 키움증권 홈페이지(이트레이딩/데일날)에서 Open API+ 서비스 소개 페이지를 통해 다운로드 후 설치
- OCX 컨트롤 방식으로 제공 (`khopenapi.ocx`)

#### 디렉토리 구조
- 설치 경로: `C:\OpenAPI\`
- 주요 파일: `khopenapi.ocx` (COM 컨트롤)

#### 개발환경
- **프로그램 개발 확장성**: OCX 컨트롤로 제작 지원
- **지원 언어**: VB, 엑셀, 웹기반, MFC, C# 등
- **데이터 요청 및 수신**: TR 서비스를 검색한 후 OCX를 통해 API 함수를 호출하는 방식

### 2. 접속하기

#### 로그인 및 버전처리
- **로그인 창 제공**: 키움 Open API는 로그인창을 제공 (공통)
- **제작한 프로그램을 통해 로그인 시 아래 절차를 참고하시면 됩니다**
- 로그인 시 로그인 창을 실행한 프로그램(Open API OCX를 탑재한 프로그램)의 열려있는 경우 버전처리 및 로그인이 진행 되지 않습니다

## 프로젝트 적용 핵심 포인트

### 1. OCX 컨트롤 기반 아키텍처
- COM Interop을 통한 C# 연동 필수
- STA(Single-Threaded Apartment) 스레드 모델 준수 필요

### 2. TR(Transaction) 기반 데이터 요청
- 각 기능(계좌 조회, 시세 조회, 주문 등)은 고유한 TR 코드로 식별
- 예: `OPT10032` (거래대금상위요청)

### 3. 이벤트 기반 비동기 처리
- 요청(Request)과 응답(Response)이 분리된 비동기 구조
- 주요 이벤트:
  - `OnReceiveTrData`: TR 요청 응답 수신
  - `OnReceiveRealData`: 실시간 시세 데이터 수신
  - `OnReceiveChejanData`: 주문 체결 데이터 수신

### 4. KOA Studio 활용
- TR 명세 확인 및 테스트를 위한 공식 도구
- Input/Output 파라미터 구조 확인 가능

## 다음 단계: 상세 TR 명세 확인 필요

이 가이드는 전체 구조와 개념을 설명하지만, **구체적인 TR 명세**(특히 해외주식 관련)는 추가 조사가 필요합니다.

### 확인 필요 사항
1. **OPT10032** (거래대금상위요청) - 국내 주식용
2. **해외주식 전용 TR** - `opw20xxx` 시리즈 (별도 문서 또는 KOA Studio에서 확인)
3. **실시간 등록 방법** (`SetRealReg`) - 300종목 분할 등록 방식
4. **호출 제한 규칙** - 1초 5회 제한 준수 방법
