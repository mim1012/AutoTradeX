# 키움증권 OPT10032 TR 상세 명세

## 출처
- **블로그**: https://trustyou.tistory.com/261
- **화면번호**: [0186] 거래대금상위

---

## TR 개요

### 기본 정보
- **TR 코드**: OPT10032
- **TR 이름**: 거래대금상위 요청
- **발생 이벤트**: OnReceiveTrData
- **화면번호**: [0186]

### 용도
거래대금 상위 종목들의 정보를 조회합니다. 시장구분(전체/코스피/코스닥)과 관리종목 포함 여부를 설정하여 상위 종목 리스트를 가져올 수 있습니다.

---

## Input 파라미터

| 파라미터명 | 설명 | 가능한 값 |
|-----------|------|----------|
| **시장구분** | 조회할 시장 선택 | `000`: 전체<br>`001`: 코스피<br>`101`: 코스닥 |
| **관리종목포함** | 관리종목 포함 여부 | `0`: 관리종목 미포함<br>`1`: 관리종목 포함 |

| **매도호가** | 매도 호가 |

| **전일거래량** | 전일 거래량 |

### 2) OnReceiveTrData 이벤트 핸들러


## 프로젝트 적용 시나리오

### 미국 주식 거래대금 상위 300종목 조회

**문제점**: OPT10032는 **국내 주식 전용** TR입니다. 미국 주식에는 사용할 수 없습니다.

**해결 방안**:
1. **해외주식 전용 TR 확인 필요**
   - `opw20xxx` 시리즈 TR 중 거래대금 조회 기능 확인
   - KOA Studio에서 해외주식 관련 TR 목록 검색

2. **대안: 실시간 시세 등록 활용**
   - 미리 정의된 300개 종목 리스트를 실시간 등록
   - 실시간 데이터를 수신하여 거래대금 계산
   - 주기적으로 순위 재정렬

3. **외부 데이터 소스 활용**
   - Yahoo Finance API, Alpha Vantage 등 외부 API로 거래대금 상위 종목 확보
   - 확보된 종목 리스트를 키움 API로 실시간 감시

## 연속 조회 (Pagination)

OPT10032는 한 번에 최대 100개 종목까지 조회 가능합니다. 300개 종목을 조회하려면 **연속 조회**가 필요합니다.

```csharp
// 첫 번째 요청
axKHOpenAPI.CommRqData("rq_opt10032", "OPT10032", 0, "0186");

// OnReceiveTrData에서 연속 조회 여부 확인
private void AxKHOpenAPI_OnReceiveTrData(
    object sender, 
    AxKHOpenAPILib._DKHOpenAPIEvents_OnReceiveTrDataEvent e)
{
    if (e.sRQName == "rq_opt10032")
    {
        ProcessOpt10032Data(e.sTrCode, e.sRecordName);
        
        // 연속 조회 가능 여부 확인
        if (e.sPrevNext == "2")
        {
            // 200ms 대기 후 다음 페이지 요청 (Throttling)
            Task.Delay(200).ContinueWith(_ => 
            {
                axKHOpenAPI.CommRqData("rq_opt10032", "OPT10032", 2, "0186");
            }, TaskScheduler.FromCurrentSynchronizationContext());
        }
    }
}
```

## 주의사항

1. **호출 제한**: 1초에 5회까지만 TR 요청 가능 (Throttling 필수)
2. **데이터 형식**: 반환되는 데이터는 문자열이므로 Trim() 및 형변환 필요
3. **시장 구분**: 국내 주식만 지원 (해외 주식은 별도 TR 사용)
4. **실시간 업데이트**: 이 TR은 일회성 조회이므로, 실시간 업데이트가 필요하면 실시간 등록 별도 필요
