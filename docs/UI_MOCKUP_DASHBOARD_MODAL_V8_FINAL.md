# 📱 AutoTradeX UI 목업 v8.0 (최종 확정판)

## 🎯 설계 목표

메인 대시보드 단일 화면에서 모든 핵심 정보를 표시하고, 계좌 관리 및 조건식 설정은 모달창으로 처리하여 직관적이고 단순한 UX를 제공한다.

### 핵심 요구사항

1. ✅ **메인 대시보드 단일 화면**: 종목 감시, 조건 충족 종목, 로그를 한 화면에 표시
2. ✅ **활성 계좌 최대 1개**: 여러 계좌 등록 가능하지만 자동매매는 1개 계좌만
3. ✅ **조건식 저장/불러오기**: 각 계좌마다 조건식을 미리 저장하고 활성 계좌 변경 시 자동 로드
4. ✅ **모달 기반 설정**: 계좌 관리, 조건식 설정은 모달창으로 처리
5. ✅ **조건식당 최대 10개 조건**: 하나의 조건식 안에 최대 10개 조건 추가
6. ✅ **로컬 DB 저장**: SQLite에 계좌 정보 및 조건식 영구 저장

### 로컬 DB 스키마 (SQLite)

```sql
-- 계좌 테이블
CREATE TABLE Accounts (
    AccountId INTEGER PRIMARY KEY AUTOINCREMENT,
    AccountNumber TEXT NOT NULL UNIQUE,  -- 계좌번호 (예: 12345678-01)
    AccountName TEXT,                     -- 계좌 별칭 (예: "메인 계좌")
    AppKey TEXT NOT NULL,                 -- KIS API AppKey
    AppSecret TEXT NOT NULL,              -- KIS API AppSecret (암호화 저장)
    IsReal BOOLEAN NOT NULL,              -- 실전(1) / 모의(0)
    IsActive BOOLEAN DEFAULT 0,           -- 활성 계좌 여부 (최대 1개만 1)
    BuyRatio REAL DEFAULT 100.0,          -- 매수 비율 (%)
    ExcludeOwnedStocks BOOLEAN DEFAULT 0, -- 관심종목 제외 옵션
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP
);

-- 조건식 테이블
CREATE TABLE ConditionSets (
    ConditionSetId INTEGER PRIMARY KEY AUTOINCREMENT,
    AccountId INTEGER NOT NULL,           -- 외래키: Accounts.AccountId
    Name TEXT DEFAULT '조건식1',          -- 조건식 이름
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (AccountId) REFERENCES Accounts(AccountId) ON DELETE CASCADE
);

-- 조건 테이블
CREATE TABLE Conditions (
    ConditionId INTEGER PRIMARY KEY AUTOINCREMENT,
    ConditionSetId INTEGER NOT NULL,      -- 외래키: ConditionSets.ConditionSetId
    ConditionOrder INTEGER NOT NULL,      -- 조건 순서 (1, 2, 3, ...)
    ConditionType TEXT NOT NULL,          -- 조건 타입 (PriceChange, MovingAverage, TradeVolume, PriceComparison)
    Parameters TEXT NOT NULL,             -- JSON 형태의 파라미터
    LogicOperator TEXT,                   -- 다음 조건과의 논리 연산자 (AND, OR)
    CreatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    UpdatedAt DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (ConditionSetId) REFERENCES ConditionSets(ConditionSetId) ON DELETE CASCADE
);

-- 인덱스
CREATE INDEX idx_conditions_conditionset ON Conditions(ConditionSetId);
CREATE INDEX idx_conditionsets_account ON ConditionSets(AccountId);

-- 제약 조건: 활성 계좌는 최대 1개
CREATE TRIGGER enforce_single_active_account
BEFORE UPDATE ON Accounts
WHEN NEW.IsActive = 1
BEGIN
    UPDATE Accounts SET IsActive = 0 WHERE AccountId != NEW.AccountId;
END;
```

### 주요 기능

#### 1. 시스템 상태 영역

**표시 항목:**
- 현재 활성 계좌 (계좌번호 + 별칭)
- 조건식 요약 (논리식 + 조건 개수)
- 시스템 상태 (🔴 중지됨 / 🟢 실행 중)
- 자동매매 시작/중지 버튼
- 마지막 업데이트 시간
- 감시 종목 수 및 조건 충족 종목 수

**버튼:**
- **[계좌 변경]**: 계좌 관리 모달 열기
- **[조건식 편집]**: 조건식 설정 모달 열기
- **[▶️ 자동매매 시작]**: 활성 계좌의 조건식으로 자동매매 시작
  - 클릭 시 버튼이 **[⏸️ 자동매매 중지]**로 변경
  - 시스템 상태가 🟢 실행 중으로 변경

#### 2. 거래대금 상위 300 종목

**컬럼:**
- 순위: 거래대금 기준 순위
- 종목코드: TSLA, AAPL, NVDA, ...
- 종목명: Tesla Inc, Apple Inc, ...
- 현재가: 실시간 가격
- 등락률: 전일 대비 등락률
- 거래대금: 당일 거래대금 (달러)
- 상태: ✅ 조건 충족 / - 조건 불충족

**동작:**
- 1분마다 자동 갱신
- 조건 충족 종목은 ✅ 표시

#### 3. 조건 충족 종목

**컬럼:**
- 순위: 거래대금 기준 순위
- 종목코드, 종목명, 현재가, 등락률
- 확인: 조건 충족 연속 횟수 (⏳0 → ✅1 → ✅2)
- 주문: 주문 우선순위 (하락률 상위 2개)

**주문 로직:**
- 조건 충족 종목 중 **하락률 상위 2개**만 주문
- 각 종목에 **50%씩** 매수
- 2회 연속 조건 충족 시에만 주문 대상 (✅2)

#### 4. 시스템 로그

**표시 형식:**
```
[시간] [레벨] [메시지]
```

**로그 레벨:**
- `[INFO]`: 일반 정보
- `[ORDER]`: 주문 실행
- `[RESULT]`: 체결 결과
- `[ERROR]`: 오류 발생

### 주요 기능

#### 1. 조건 목록 (최대 10개)

**제한 사항:**
- 최대 10개까지 조건 추가 가능
- 10개 도달 시 [+ 조건 추가] 버튼 비활성화
- 조건 개수 표시: "(3/10)"

**조건 카드 구조:**
- 체크박스: 조건 활성화/비활성화
- 조건 번호: 조건1, 조건2, ... (자동 할당)
- 조건 타입: [등락률], [이동평균선], [거래대금], [주가 비교]
- 조건 설명: 자연어 텍스트
- 상태 메시지: 실시간 조건 충족 여부
- 편집/삭제 버튼
- 논리 연산자 선택 (마지막 조건 제외)

#### 2. 조건 추가 버튼

**클릭 시:**
- `ConditionEditorDialog` 모달 열기
- 4가지 조건 타입 중 선택
- 조건 파라미터 입력
- 저장 시 조건 목록에 추가

#### 3. 조건 충족 종목 실시간 미리보기

**동작:**
- 현재 조건식을 실시간으로 평가
- 조건 충족 종목만 필터링하여 표시
- 관심종목 제외 옵션이 체크되어 있으면 보유 종목 자동 제외

#### 4. 저장 버튼

**동작:**
- 현재 조건 목록을 로컬 DB에 저장
- 저장 성공 시: ✅ "조건식이 저장되었습니다."
- 모달 닫기

#### 5. 테스트 실행 버튼

**동작:**
- 현재 조건식으로 즉시 조건 평가 실행
- 조건 충족 종목 미리보기 영역 업데이트
- 저장하지 않고 테스트만 가능

### 주요 기능

#### 1. 기본 정보

**입력 필드:**
- 계좌번호: 한국투자증권 계좌번호 (예: 12345678-01)
- 계좌 별칭: 사용자 지정 이름
- 구분: 실전 / 모의 (라디오 버튼)

#### 2. API 인증 정보

**입력 필드:**
- AppKey: 마스킹 표시 (********)
- AppSecret: 마스킹 표시 (********)
- [표시] 버튼: 클릭 시 평문 표시

**API 연결 테스트 버튼:**
- 입력한 AppKey/AppSecret으로 KIS API 인증 테스트
- 성공 시: ✅ "API 연결 성공"
- 실패 시: ❌ "API 연결 실패: [오류 메시지]"

**입력 필드:**

- 관심종목 제외: 체크박스

**동작:**
- 입력 검증
  - 계좌번호: 필수 입력
  - AppKey/AppSecret: 필수 입력
  - 매수 비율: 0 ~ 100 범위
- 저장 성공 시: ✅ "계좌가 저장되었습니다."
- 모달 닫기

## 🔧 핵심 워크플로우

### 1. 계좌 추가 및 조건식 설정 플로우

```
1. 메인 대시보드에서 [계좌 변경] 버튼 클릭
   ↓
2. 계좌 관리 모달 열림
   ↓
3. [+ 계좌 추가] 버튼 클릭
   ↓
4. 계좌 상세 정보 모달 열림
   ↓
5. 계좌번호, AppKey, AppSecret 입력
   ↓
6. [API 연결 테스트] 버튼 클릭 → ✅ 성공
   ↓
7. [저장] 버튼 클릭 → 로컬 DB에 계좌 추가
   ↓
8. 계좌 관리 모달에서 새 계좌의 라디오 버튼 ⚫ 선택
   ↓
9. [확인] 버튼 클릭 → 활성 계좌 변경
   ↓
10. 메인 대시보드에서 [조건식 편집] 버튼 클릭
    ↓
11. 조건식 설정 모달 열림
    ↓
12. [+ 조건 추가] 버튼 클릭
    ↓
13. ConditionEditorDialog에서 조건 설정
    - 조건 타입: 등락률
    - 기준봉: 일봉
    - 범위: -7.0% ~ 0.0%
    ↓
14. [추가] 버튼 클릭 → 조건1 추가
    ↓
15. 논리 연산자 선택: AND
    ↓
16. 조건2, 조건3, ... 반복 추가 (최대 10개)
    ↓
17. [저장] 버튼 클릭 → 로컬 DB에 저장
    ↓
18. 메인 대시보드에서 [▶️ 자동매매 시작] 버튼 클릭
    ↓
19. 자동매매 시작!
```

### 2. 활성 계좌 변경 플로우

```
현재 활성 계좌: 계좌1 (12345678-01)

1. 메인 대시보드에서 [계좌 변경] 버튼 클릭
   ↓

   ↓

   ↓

   ↓

   ↓
6. 메인 대시보드에 계좌2 정보 및 조건식 표시
   ↓
7. [▶️ 자동매매 시작] 버튼 클릭
   ↓
8. 계좌2의 조건식으로 자동매매 실행!

### 3. 조건식 저장/불러오기 플로우

```
계좌1: 조건식 저장됨 ✅
