## 4. 핵심 발견 사항

### ✅ 프로젝트 요구사항 충족 여부

| PRD 요구사항 | API 지원 여부 | 비고 |
|-------------|--------------|------|
| **거래대금 상위 300종목 조회** | ✅ **완벽 지원** | `output2` 배열로 반환 |
| **미국 주식 (뉴욕, 나스닥)** | ✅ **완벽 지원** | EXCD='NYS' 또는 'NAS' |
| **ETF/레버리지 포함** | ✅ **포함됨** | 별도 필터 없이 모두 포함 |
| **실시간 갱신** | ✅ **가능** | 10~15분 주기 호출 권장 |

### 🎯 프로젝트 적용 방안

1. **초기 호출**: 프로그램 시작 시 1회 호출하여 상위 300종목 확보
2. **주기적 갱신**: 10~15분마다 재호출하여 리스트 업데이트
3. **거래소 분리**: 
   - NYS(뉴욕) 호출 → 상위 150종목
   - NAS(나스닥) 호출 → 상위 150종목
   - 합산하여 총 300종목 확보
4. **필터 설정**:
   - `VOL_RANG=0` (전체)
   - `PRC1=0`, `PRC2=999999` (가격 제한 없음)
   - `NDAY=0` (당일 기준)

## 5. 주의사항

### 5.1. 모의투자 미지원

**중요**: 이 API는 **모의투자를 지원하지 않습니다.** 테스트를 위해서는 실전 계좌로 소액 거래를 진행해야 합니다.

### 5.2. API 호출 제한

한국투자증권 API는 **1초당 최대 20회** 호출 제한이 있습니다. 거래대금 순위 조회는 조회 API이므로, 다른 시세 조회 및 주문 API와 호출 횟수를 공유합니다.

**권장 호출 주기**: 10~15분마다 1회

### 5.3. 연속 조회

만약 한 번의 호출로 300종목을 모두 받지 못하는 경우, `tr_cont` 헤더를 사용하여 연속 조회가 가능합니다.

## 9. 중요 참고 사항

### 9.1. Access Token 발급

이 API를 호출하기 전에 반드시 **Access Token**을 먼저 발급받아야 합니다.

**Token 발급 API**:
- **URL**: `/oauth2/tokenP` (POST)
- **필요 정보**: appkey, appsecret
- **유효기간**: 
  - 개인: 1일
  - 법인: 3개월 (Refresh Token 사용 시 갱신 가능)

### 9.2. API 호출 제한 (Throttling)

한국투자증권 API는 다음과 같은 호출 제한이 있습니다:

| 구분 | 제한 |
|------|------|
| **초당 호출 횟수** | 최대 20회 |
| **분당 호출 횟수** | 최대 1,000회 |

**권장 사항**:
- 거래대금 순위 조회는 **10~15분마다 1회** 호출
- Throttling Queue를 구현하여 호출 간격을 자동으로 관리

### 9.3. 연속 조회 (Pagination)

만약 한 번의 호출로 모든 종목을 받지 못하는 경우:

1. 첫 호출: `tr_cont` 헤더를 비워둠 (또는 생략)
2. 응답의 `tr_cont` 값 확인
3. 다음 호출: 응답받은 `tr_cont` 값을 요청 헤더에 포함
