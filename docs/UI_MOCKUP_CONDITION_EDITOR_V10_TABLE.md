# 🎨 조건식 설정 UI 모달 목업 v10.0 (테이블 형식)

## 🎯 핵심 아이디어

**테이블 형식**으로 조건들을 한 줄씩 표시하고, 하단에 **조건식 편집기**로 AND/OR를 조합하는 방식입니다.

참고 이미지와 동일한 구조로 설계했습니다.

## 🎨 UI 구성 요소

### 1. 조건 목록 (테이블)

```
┌─ 조건 목록 ────────────────────────────────────────────────────────────┐
│ ✓ │ ID │ 조건 내용                                    │ 삭제 │ ▲▼ │    │
│───┼────┼──────────────────────────────────────────────┼──────┼─────┤    │
│ ☑ │ J  │ 등락률:[일]1봉전(종) 종가대비 0봉전 종가등락률 -7%이하│ X │ ▲▼ │    │
│ ☑ │ K  │ 주가비교:[일]1봉전 종가 >= 0봉전 고가              │ X │ ▲▼ │    │
│ ☑ │ L  │ 등락률:[주]2봉전(종) 종가대비 1봉전 고가등락률 10%이상│ X │ ▲▼ │    │
│ ☑ │ M  │ [일]거래대금(일:백만, 분:천) 1000이상 9999999999이하│ X │ ▲▼ │    │
│ ☑ │ N  │ 주가비교:[일]2봉전 저가 >= 1봉전 저가 >= 0봉전 저가 │ X │ ▲▼ │    │
└─────────────────────────────────────────────────────────────────────────┘
```

**컬럼:**
1. **✓ (체크박스)**: 조건 활성화/비활성화
2. **ID**: 조건 식별자 (A, B, C, ..., J, K, ...)
3. **조건 내용**: 조건 설명 (한 줄로 표시)
4. **삭제 (X)**: 조건 삭제 버튼
5. **▲▼**: 조건 순서 변경 버튼

**특징:**
- 한 줄에 하나의 조건 표시
- 최대 10개까지 표시 가능
- 체크박스로 조건 활성화/비활성화
- ID는 자동 생성 (A, B, C, ...)

### 2. 조건식 편집기

```
┌─ 조건식 편집기 ─────────────────────────────────────────────────────────┐
│ 조건식: [ G ] [and▼] [ H ] [and▼] [ I ] [and▼] [ J ] [and▼] [ K ]      │
│         [and▼] [ L ] [and▼] [ M ] [and▼] [ N ]                          │
│                                                                          │
│  💡 조건 ID를 클릭하여 추가/제거, 드롭다운으로 AND/OR 선택               │
│  💡 괄호 버튼: [ ( ]  [ ) ]  [ ⊗ ] (괄호 삭제)  [ X ] (조건 제거)       │
└──────────────────────────────────────────────────────────────────────────┘
```

**구성 요소:**
1. **조건 ID 버튼**: 클릭하여 조건 추가/제거
   - 예: `[ G ]`, `[ H ]`, `[ I ]`
   - 클릭 시 해당 조건이 조건식에 추가됨

2. **AND/OR 드롭다운**: 조건 사이의 논리 연산자
   - `[and▼]`, `[or▼]`
   - 드롭다운으로 선택

3. **괄호 버튼**:
   - `[ ( ]`: 여는 괄호 추가
   - `[ ) ]`: 닫는 괄호 추가
   - `[ ⊗ ]`: 괄호 쌍 삭제
   - `[ X ]`: 조건 제거

**동작:**
- 조건 ID를 클릭하면 조건식에 추가
- AND/OR 드롭다운으로 논리 연산자 선택
- 괄호로 복잡한 논리식 구성 가능

## 🔄 워크플로우

### 시나리오 1: 조건 추가 및 조건식 구성

```
1. [+ 조건 추가] 버튼 클릭
   → 조건 추가 다이얼로그 열림
   → 조건 타입 선택 (등락률, 주가비교, 거래대금, ...)
   → 파라미터 입력
   → [확인] 클릭
   → 조건 목록에 새 조건 추가 (ID: J)

2. 조건식 편집기에서 조건 ID 클릭
   → [ J ] 버튼 클릭
   → 조건식에 "J" 추가

3. AND/OR 드롭다운 선택
   → [and▼] 선택

4. 다른 조건 ID 클릭
   → [ K ] 버튼 클릭
   → 조건식에 "J and K" 표시

5. 조건식 미리보기 확인
   → "J and K"

6. 조건 충족 종목 미리보기 확인
   → 실시간으로 충족 종목 표시

7. [저장] 버튼 클릭
   → DB에 저장
   → 모달 닫기
```

---

### 시나리오 2: 복잡한 조건식 구성 (괄호 사용)

```
조건식: (G and H) or (I and J)

1. [ ( ] 버튼 클릭 → "(" 추가
2. [ G ] 버튼 클릭 → "(G" 추가
3. [and▼] 선택 → "(G and" 추가
4. [ H ] 버튼 클릭 → "(G and H" 추가
5. [ ) ] 버튼 클릭 → "(G and H)" 추가
6. [or▼] 선택 → "(G and H) or" 추가
7. [ ( ] 버튼 클릭 → "(G and H) or (" 추가
8. [ I ] 버튼 클릭 → "(G and H) or (I" 추가
9. [and▼] 선택 → "(G and H) or (I and" 추가
10. [ J ] 버튼 클릭 → "(G and H) or (I and J" 추가
11. [ ) ] 버튼 클릭 → "(G and H) or (I and J)" 추가

조건식 미리보기: (G and H) or (I and J)
```

---

### 시나리오 3: 조건 삭제

```
1. 조건 K의 [X] 버튼 클릭
   → 확인 다이얼로그 표시
   → [확인] 클릭
   → 조건 K 삭제
   → 조건식 편집기에서 K도 자동 제거
   → 조건식 미리보기 업데이트
```

## 📝 조건 추가 다이얼로그

조건을 추가할 때는 **별도의 다이얼로그**를 사용합니다:

```
┌─────────────────────────────────────────────────────────────┐
│  ➕ 조건 추가                                                │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  조건 타입: [등락률 ▼]                                       │
│                                                              │
│  기준봉: [일봉 ▼]                                            │
│  몇 봉 전: [0 ▼]                                             │
│  비교 기준: [종가 ▼]                                         │
│  등락률 범위: [-7.0] % ~ [0.0] %                             │
│                                                              │
│                                          [ 확인 ]  [ 취소 ]  │
└─────────────────────────────────────────────────────────────┘
```

## 🎯 핵심 기능

### 1. 테이블 형식으로 조건 표시

- 한 줄에 하나의 조건
- 최대 10개까지 표시
- 공간 효율적

### 2. 조건식 편집기

- 조건 ID 버튼으로 조건 추가
- AND/OR 드롭다운으로 논리 연산자 선택
- 괄호로 복잡한 논리식 구성

### 3. 실시간 미리보기

- 조건식 미리보기: 논리식 텍스트 표시
- 조건 충족 종목 미리보기: 실시간으로 충족 종목 표시

### 4. 드래그 앤 드롭 (선택 사항)

조건식 편집기에서 조건 ID를 **드래그 앤 드롭**으로 순서 변경할 수 있습니다.
