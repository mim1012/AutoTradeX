## 📸 키움증권 HTS 조건식 UI 분석

제공하신 스크린샷에서 확인한 구조:

```
┌─────────────────────────────────────────────────────────────────┐
│ ☑ J  주가등락률:[일]1봉전(중) 종가대비 0봉전 종가등락률 -7%이하  │
│ ☑ K  주가비교:[일]1봉전 종가 >= 0봉전 고가                      │
│ ☑ L  주가등락률:[주]2봉전(중) 종가대비 1봉전 고가등락률 10%이상  │
│ ☑ M  [일]거래대금(일*백만, 분*천) 100이상 <= 300이하            │
│ ☑ N  주가비교:[일]2봉전 저가 >= 1봉전 저가 >= 0봉전 저가        │
├─────────────────────────────────────────────────────────────────┤
│ 조건식 | B and H and I and J and K and L and M and N  [▼]       │
└─────────────────────────────────────────────────────────────────┘
```

**핵심 특징:**
1. **체크박스 리스트**: 각 조건이 한 줄로 표시되며, 체크박스로 활성화/비활성화
2. **조건 ID**: J, K, L, M, N 등 알파벳으로 각 조건 식별
3. **자연어 표현**: 조건이 읽기 쉬운 한국어 문장으로 표시
4. **하단 논리식**: "B and H and I and J and K and L and M and N" 형태로 조합 표시

## 📋 조건 목록 (체크박스 리스트)

### 조건 항목 구조

각 조건은 다음과 같은 형식으로 표시된다:

```
☑ [ID]  [조건 설명 텍스트]
        상태: ✅/❌ 충족/불충족 (예시 데이터)
        [편집] [삭제]
```

### 예시

#### A) 등락률 조건

```
☑ A  등락률: [일봉] 0봉 전 종가 대비 -7.0% ~ 0.0%
     상태: ✅ 충족 (TSLA: -5.2%, NVDA: -3.8%)
     [편집] [삭제]
```

#### B) 이동평균선 조건

```
☑ B  이동평균: 현재가가 20일 이평선 대비 -3.0% ~ +3.0% 이내
     상태: ❌ 불충족 (AAPL: +5.8%)
     [편집] [삭제]
```

#### C) 거래대금 조건

```
☑ C  거래대금: 1,000만 달러 이상
     상태: ✅ 충족 (280/300 종목)
     [편집] [삭제]
```

#### D) 주가 비교 조건

```
☑ D  주가비교: [일봉] 0봉 시가 > 1봉 저가
     상태: ✅ 충족 (TSLA, NVDA, AMD)
     [편집] [삭제]
```

## 🔗 조건식 조합 영역

### 기본 형식

```
┌─ 🔗 조건식 조합 ──────────────────────────────┐
│                                               │
│  조건식: A and B                  [▼ 편집]    │
│                                               │
│  💡 설명: 조건 A와 조건 B가 모두 충족되어야   │
│          합니다.                              │
│                                               │
└───────────────────────────────────────────────┘
```

### 논리식 편집 모드

"[▼ 편집]" 버튼을 클릭하면 드롭다운이 열리며, 논리 연산자를 변경할 수 있다:

```
┌─ 조건식 편집 ─────────────────────────┐
│                                       │
│  [A ▼] [and ▼] [B ▼]                 │
│                                       │
│  [ + 조건 추가 ]                      │
│                                       │
│  논리 연산자:                         │
│  • and: 모든 조건 충족                │
│  • or:  하나라도 충족                 │
│                                       │
│  [ 적용 ]  [ 취소 ]                  │
│                                       │
└───────────────────────────────────────┘
```

### 복잡한 조합 예시

```
조건식: (A and B) or C

💡 설명: 조건 A와 B가 모두 충족되거나,
        조건 C가 충족되면 매수합니다.
```

```

│                                                               │

│                                                               │
│  순위 │ 종목코드 │ 종목명     │ 현재가   │ 등락률  │ 거래대금  │ 확인│
│  ─────┼─────────┼───────────┼─────────┼────────┼──────────┼─────│
```

**확인 횟수 설명:**
- `⏳ 0회`: 조건 충족 시작 (5초 후 재확인)
- `✅ 1회`: 1회 확인 완료 (5초 후 재확인)
- `✅ 2회`: 2회 연속 확인 (후보 확정, 주문 대기)

## 🔄 인터랙션

### 1. 조건 추가

```
[+ 조건 추가] 버튼 클릭
    ↓
모달 창 열림 (조건 타입 선택)
    ↓
조건 타입 선택 (예: 등락률)
    ↓
파라미터 입력 (예: -7% ~ 0%)
    ↓
[추가] 버튼 클릭
    ↓
조건 목록에 새 항목 추가 (ID: A, B, C, ...)
    ↓
자동으로 조건식에 추가 (예: "A" → "A and B")
```

### 2. 조건 편집

```
조건 항목의 [편집] 버튼 클릭
    ↓
모달 창 열림 (기존 값으로 채워짐)
    ↓
파라미터 수정
    ↓
[저장] 버튼 클릭
    ↓
조건 설명 텍스트 업데이트
    ↓
실시간 조건 충족 상태 재평가
```

### 3. 조건 삭제

```
조건 항목의 [삭제] 버튼 클릭
    ↓
확인 다이얼로그: "이 조건을 삭제하시겠습니까?"
    ↓
[Yes] 클릭
    ↓
조건 목록에서 제거
    ↓
조건식에서도 자동 제거 (예: "A and B and C" → "A and C")
```

### 4. 조건식 편집

```
조건식 영역의 [▼ 편집] 버튼 클릭
    ↓
드롭다운 열림 (논리 연산자 선택)
    ↓
연산자 변경 (예: "and" → "or")
    ↓
[적용] 버튼 클릭
    ↓
조건식 텍스트 업데이트 (예: "A and B" → "A or B")
    ↓
설명 텍스트 자동 업데이트
```

## 💾 데이터 모델

### ViewModel: `ConditionBuilderViewModel`

```csharp
public class ConditionBuilderViewModel : ViewModelBase
{
    // 조건 목록
    public ObservableCollection<ConditionItemViewModel> Conditions { get; }
    
    // 조건식 텍스트 (예: "A and B or C")
    public string LogicExpression { get; set; }
    
    // 조건식 설명 텍스트
    public string LogicExplanation { get; set; }
    
    // 조건 충족 종목
    public ObservableCollection<StockInfo> MatchedStocks { get; }
    
    // Commands
    public ICommand AddConditionCommand { get; }
    public ICommand EditConditionCommand { get; }
    public ICommand RemoveConditionCommand { get; }
    public ICommand EditLogicExpressionCommand { get; }
    public ICommand SaveConditionsCommand { get; }
    public ICommand TestConditionsCommand { get; }
}
```

### Model: `ConditionItemViewModel`

```csharp
public class ConditionItemViewModel : ViewModelBase
{
    // 조건 ID (A, B, C, ...)
    public string Id { get; set; }
    
    // 활성화 여부
    public bool IsEnabled { get; set; }
    
    // 조건 타입
    public ConditionType Type { get; set; }
    
    // 조건 설명 텍스트 (예: "등락률: [일봉] 0봉 전 종가 대비 -7.0% ~ 0.0%")
    public string Description { get; set; }
    
    // 실시간 상태
    public bool IsConditionMet { get; set; }
    public string StatusMessage { get; set; }
    
    // 조건 파라미터 (타입별로 다름)
    public Dictionary<string, object> Parameters { get; set; }
}
```
